# מדריך ניווט בקוד — לאורן

מדריך אישי כדי להתמצא בריפו ולדעת איפה למצוא/לשנות כל דבר.

---

## באיזו שפה הכל כתוב

האתר בנוי מ־**HTML + CSS + JavaScript**, לא פייתון:

- **HTML** — המבנה של הדף (טקסטים, תמונות, כפתורים — "מה יש בדף").
- **CSS** — העיצוב (צבעים, מרווחים, גדלים — "איך זה נראה").
- **JavaScript (JS)** — ההתנהגות (מה קורה בלחיצה, אנימציות — "מה קורה כשמשתמשים בדף").

פייתון היא שפה נפרדת (בדרך כלל לא רצה בדפדפן), אז זה לא "המשך" ללימוד פייתון — אבל ההיגיון (משתנים, תנאים, לולאות, פונקציות) עובר בין שפות ויעזור לך להבין את הקוד כאן.

## מפת תיקיות

```
index.html              ← דף הבית עצמו (המבנה שלו)
pages/                  ← 9 עמודי העבודות (work-1.html עד work-9.html)
media/                  ← CSS + JS + אייקונים של האתר עצמו
  ├─ styles.css         ← עיצוב דף הבית
  ├─ work-page.css      ← עיצוב משותף לכל 9 עמודי העבודות
  ├─ home.js            ← ההתנהגות (JS) של דף הבית — כפתור השתקה, אנימציות טקסט וכו'
  ├─ work-page.js        ← JS משותף לעמודי העבודות (למשל האייקונים בתחתית)
  └─ work-mute.js        ← JS של כפתור ההשתקה בעמודי העבודות
my_web/                 ← תוכן/מדיה של כל עבודה בנפרד (סרטונים, תמונות, פונטים)
raw-sources/            ← חומר גלם שעוד לא פורסם באתר (לא חלק מהאתר החי)
```

## הבלבול הכי גדול: שם הקובץ ≠ מספר בקוד

**שם הקובץ בתיקיית `pages/` לא תואם למספר הפנימי בקוד.** מפה מלאה (נבדק בפועל):

| קובץ | עבודה בפועל | class פנימי |
|---|---|---|
| `pages/work-1.html` | Sunset | `work-8` |
| `pages/work-2.html` | Animix festival | `work-1` |
| `pages/work-3.html` | Chasing Stars | `work-9` |
| `pages/work-4.html` | Animix festival (כותרת כפולה — באג ידוע, לא תוקן) | `work-2` |
| `pages/work-5.html` | Your way to Save time | `work-3` |
| `pages/work-6.html` | 3D Animation | `work-4` |
| `pages/work-7.html` | My Exercises | `work-5` |
| `pages/work-8.html` | 3D Rigging | `work-6` |
| `pages/work-9.html` | Jazz night | `work-7` |

**למה זה משנה:** ב־`work-page.css` כתובים כללים לפי ה־class הפנימי (למשל `.work-page.work-8 .something`), לא לפי שם הקובץ. אם תחפש "עמוד 1" ותחפש `work-1` ב־CSS, תמצא בטעות את Animix ולא את Sunset.

**הכלל:** לפני שנוגעים בעמוד ספציפי — קודם פותחים את הקובץ ומחפשים את השורה `<body class="work-page work-X">` בראש הדף. זה המספר האמיתי לחיפוש ב־CSS.

## איך בפועל למצוא/לשנות משהו בעמוד מסוים

1. פותחים את `pages/work-N.html` (לפי שם הקובץ) — שם ה**מבנה** (טקסטים, תמונות, כפתורים) של אותו עמוד.
2. מוצאים בשורות הראשונות את ה־class הפנימי (`work-X`) לפי הטבלה למעלה.
3. אם זה **עיצוב** (צבע, מרווח, גודל) — מחפשים ב־`media/work-page.css` לפי אותו `work-X`.
4. אם זה **התנהגות** (לחיצה, אנימציה) — זה ב־`media/work-page.js` או `media/work-mute.js`.

דף הבית עובד אותו דבר, בלי המספור המבלבל:

- מבנה → `index.html`
- עיצוב → `media/styles.css`
- התנהגות → `media/home.js`
